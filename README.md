# MOVE — 운동 카운터

운동 종류를 구분하지 않고 운동을 마칠 때마다 횟수를 쌓는 간단한 웹앱입니다.

- **운동 완료 +1**: 같은 날에도 여러 번 기록합니다.
- **횟수 직접 입력**: 원하는 날짜에 여러 회를 한 번에 더합니다.
- **100회마다 1박 트로피**: 누적 100회는 1개, 200회는 2개, 300회는 3개입니다.
- **달력**: 날짜별 총횟수를 확인하고 수정합니다. 0회로 수정하면 해당 날짜의 기록이 취소됩니다.
- **되돌리기**: 방금 한 변경을 취소합니다.
- **CSV 내보내기**: 날짜별 운동 기록을 파일로 저장합니다.

## 실행 및 배포

별도의 설치나 서버 없이 `index.html`로 실행하는 정적 웹앱입니다. GitHub Pages는 `main` 브랜치의 `/ (root)`를 배포합니다. `index.html`을 수정해 커밋하면 Pages가 자동으로 갱신됩니다.

## 기록 저장

운동 기록은 각 기기의 브라우저 저장소에만 보관됩니다. GitHub 저장소에 개인 운동 기록을 업로드하지 않으며, 기기 사이에 자동으로 동기화되지 않습니다. 브라우저 데이터를 삭제하기 전 CSV 파일을 내보내 보관하세요.
